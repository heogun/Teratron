# Teratron 하드웨어 BOM 기준

## 문서의 의미

이 문서는 대화에서 채택한 **부품 구성과 수량 배정**을 기록한다.
소자값·품종 세부 선정이나 전기적 검증이 남았다는 이유로 이미 정한 구성을 미정으로 되돌리지 않는다.
반대로 이 부품 배정표를 완성 회로도나 PCB 동작 보증으로 해석하지 않는다.
남은 구조적 결정은 [설계 상태 기록](hardware_design_status.md)에 모았다.

참고 원본:

- 루트 `Gigatron-BillOfMaterials.xlsx` (2020-06-23)
- `Gigatron Rev. 2012 OSH/Kicad/Gigatron.xml` 및 계층 회로도
- `Gigatron-manual.pdf`, `Instructions set.pdf`, 로컬 `datasheet/`

참고 소스는 수정하지 않는다. 아래 U 번호는 원본 대조용이며 새 PCB 참조번호가 아니다.
BOM은 HCT 중심이고 구형 KiCad에는 LS 표기가 섞여 있다. 논리 기능을 유지하면서 HC로 선정한다.

기존 fetch 래치·버퍼의 기능/패키지를 유지하는 배정 기준이다. 클록 연결과 리셋 연결은 새 설계에서 조정한다.
원본 EPROM U7, RAM U36, 게임패드 입력 U39는 아래 대체품과 중복 계상하지 않는다.
원본 전체는 U 참조번호 기준 39개다.

리셋 IC 1개는 원본 재사용 비교 기준이다. BOM의 MCP100-450DI/TO와 구형 KiCad의
MCP100-475DI 표기를 구분한다. RC+슈미트 리셋으로 대체할지와 엄격한 DIP-only 조건에서의
패키지 처리는 별도 결정이다. 이 비교용 1개를 새 POR 구성과 중복해 더하지 않는다.

**위에 열거한 배정은 36 + 20 = 56개 IC**다. 이것은 현재 선택한 패키지 구성의 합계이며,
아직 남은 시스템 구조 결정을 모두 반영한 최종 최소 총수나 제작용 BOM이라는 뜻은 아니다.
원본 리셋 IC 1개와 기존 fetch 패키지 3개를 유지한다는 위 기준을 포함한다.
이전 대화의 41/43/46개는 범위가 다른 부분합이므로 현재 총수로 사용하지 않는다.

추가 74HC08 ×1은 **선택안**으로만 논의됐다. 위 56개에는 포함하지 않는다.
실행/접근 뱅크를 별도 저장할 경우 필요한 저장소·선택기 등도 아직 위 표에 추가 배정하지 않았다.
부팅 전용 하위 16비트 DMA 카운터는 **0개**다. PC를 재사용한다.
두 245를 부팅용·CPU용으로 각각 다시 더하지 않는다. 부팅의 직접 레인 연결 및 공유 여부는
전체 버스 제어표로 정리하며, 표의 2개는 두 CPU 바이트 레인용 기준이다.

## PS/2 부품 배정: 고정 후 보류

사용자 결정으로 PS/2 추가 논의는 보류한다. 정확한 모델과 R/C 값은 나중에 산출한다.

- IC: 74HC595 ×2, 74HC161 ×1, 공유 74HC14 ×1. 모두 위 표에 포함됐다.
- NPN: **총 2개** — CLK inhibit 1개, 워치독 커패시터 방전 1개. IC 합계에서 제외한다.
- 제어: 기존/추가 배정된 74HC00·74HC32·74HC14 여유 게이트를 할당한다.
  별도 PS/2용 D-FF/모노스테이블 IC는 추가하지 않는 구성 기준이다.
- READY/INHIBIT 상태는 교차결합 NAND **2개**의 SR 래치로 유지한다.
  74HC14 인버터 두 개를 외부 SET/RESET이 있는 NAND SR 래치의 대체품으로 계산하지 않는다.
- 4비트 nonzero는 2입력 OR **3개**, NOT READY 결합은 논리 **1개**를 배정한다.
- 11 검출·래치 스트로브·인터락까지 실제 게이트 번호별 자원 장부를 작성할 필요가 있다.
  서로 다른 기능에 같은 여유 게이트를 중복 배정하지 않는다. 이는 선택 수량을 되돌리는 사유가 아니라
  선택 구성 안에서 완성할 연결 작업이며, 실제 충돌이 발견되면 해당 변경만 명시한다.
- 다이오드·전류 제한 저항·타이밍/미분 커패시터·바이어스/복귀 경로를 별도 수동소자 BOM으로 정리한다.

## 전기적 검증은 부품 수량 결정과 구분

- HC 치환의 메모리 출력/입력 레벨 보장, 팬아웃, 발진·다이오드 디코딩을 확인한다.
- 대표 지연값 차이로 hold time을 보장했다고 하지 않는다. 최소/최대 지연과 setup/hold로 검증한다.
- 단일 포트 I-RAM의 fetch/CPU 접근 일정은 [설계 상태 기록](hardware_design_status.md)의 핵심 구조 쟁점이다.
- 에뮬레이터는 아직 각각 512KiB I-RAM/Flash 모델이며 실물 각 1MiB와 다르다.
  문서 변경은 코드·펌웨어 용량이나 동작을 바꾸지 않는다.
